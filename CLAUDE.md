# DrawVault — Enterprise DMS · Project Context

## Overview
**DrawVault** is an Enterprise Drawing Management System (DMS) demo.  
It manages construction drawings, transmittals, and document control workflows for a fictional project (Orion Tower, Dubai — ORI-2024).

## Backend API contract

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/drawings` | Returns the full drawings array as JSON |
| `POST` | `/api/upload` | Accepts `multipart/form-data`; returns `{ path }` |

**POST `/api/upload` fields:**
`drawingFile`, `drawingNumber`, `title`, `discipline`, `revision`, `originator`, `status`, `notes`

---

## State architecture

- **Drawings** — initialise as `[]`, fetched from `GET /api/drawings` on mount; re-fetched after every successful upload (never manually appended to state).
- **Transmittals** — initialise from `localStorage` (key `dv_transmittals`), seeded from `MOCK_TRANSMITTALS` on first load; synced back to localStorage via `useEffect`.
- **RBAC** — `activeRole` dropdown in the header; `isRestricted = role === "Subcontractor" || "Read-Only"` hides Upload button, Create Transmittal button, and table More-menu.

---

## Key architectural decisions

| Decision | Reason |
|----------|--------|
| All components at module scope | Fixes focus-loss bug: components defined inside other components get a new reference every render, causing React to unmount+remount and losing input focus |
| Re-fetch after upload instead of appending | Table stays perfectly in sync with DB; avoids optimistic-update drift |
| `Date.now()` for IDs | Avoids collision after row deletions (vs `length + 1`) |
| Transmittals in localStorage (not backend) | Backend transmittal persistence not yet implemented |

---

## RBAC roles

`Document Controller` · `Project Manager` · `Internal User` · `Subcontractor` · `Read-Only`

Restricted roles (Subcontractor, Read-Only) cannot upload drawings, create transmittals, or access the row More-menu.

## ⚠️ Pending fix before first `npm run dev`

The Vite migration wrote `src/` to the project root instead of inside `dms-frontend/`.  
Copy the files over before running the dev server:

```bash
cp -r src/* dms-frontend/src/
cd dms-frontend
npm install lucide-react
npm run dev
```
